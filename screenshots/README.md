# Screenshots for Chrome Web Store

Chrome Web Store requires at least **1 screenshot** (1280x800 or 640x400 PNG).
Recommended: **5-6 screenshots** showing different features.

## Required Screenshots

| # | File Name | Description | Size |
|---|---|---|---|
| 1 | `screenshot-01-studio-panel.png` | Studio Panel — model selection, prompt, result preview | 1280x800 |
| 2 | `screenshot-02-aipass-integration.png` | AiPASS answer toolbar with Varo icon embedded | 1280x800 |
| 3 | `screenshot-03-side-panel.png` | Side Panel — balance, jobs, history | 640x400 |
| 4 | `screenshot-04-options.png` | Options page — one-click connect, key entry | 1280x800 |
| 5 | `screenshot-05-context-menu.png` | Right-click context menu on an image | 1280x800 |
| 6 | `screenshot-06-video-result.png` | Video generation result example | 1280x800 |

## How to Take Screenshots

1. Load the extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked)
2. Open `https://de.aipass.net/chat` (or any page)
3. Use Chrome DevTools to set viewport to 1280x800
4. Take screenshots showing each feature
5. Save as PNG in this folder

## Small Promo Tile (optional)

Chrome Web Store also accepts:
- **Small Promo Tile** — 440x280 PNG (for promotional display in the store)
- **Marquee Promo Tile** — 1400x560 PNG (for featured extensions)

## Tips

- Use light mode for AiPASS screenshots (matches the extension's light theme)
- Show realistic content (not placeholder text)
- Highlight the orange Varo UI elements
- Ensure no personal/confidential data is visible
